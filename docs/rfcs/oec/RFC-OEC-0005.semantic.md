# RFC-OEC-0005 — Route Hashing and Deterministic Addressing

Status: Draft
Category: Semantic
Version: 0.1.0
Depends-On: RFC-OEC-0004

- Hash algorithm MUST be declared.
- Secret material MUST be referenced indirectly.
- Hash input fields MUST be explicitly ordered.
- Equivalent semantic requests MUST produce equivalent route-hash input material.
- Bindings MUST validate the same route-hash semantics.
