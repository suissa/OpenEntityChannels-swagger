# RFC-OEC-0130 — MCP Channel Binding

Status: Draft
Category: Channel Binding
Version: 0.1.0
Depends-On: RFC-OEC-0000, RFC-OEC-0003, RFC-OEC-0004

- MCP channel name MUST be stable within visibility scope.
- visibility MUST be explicit.
- Tools SHOULD bind to canonical Behavior identifiers.
- Tool schemas MUST derive from canonical OEC schemas.
- Tool names MUST NOT replace Behavior identifiers.
