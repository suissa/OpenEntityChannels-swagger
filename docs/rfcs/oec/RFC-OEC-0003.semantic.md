# RFC-OEC-0003 — Behavior Binding

Status: Draft
Category: Semantic
Version: 0.1.0
Depends-On: RFC-OEC-0000

- Behavior identifiers MUST be transport-independent.
- Channel bindings MUST reference the same Behavior for the same semantic action.
- Operations without a Behavior MUST be explicitly primitive or unresolved.
- Generators MUST NOT fabricate empty Behavior bindings as meaningful operations.
