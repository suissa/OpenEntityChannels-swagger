# RFC-OEC-0400 — Conformance Model

Status: Draft
Category: Conformance
Version: 0.1.0
Depends-On: RFC-OEC-0000

Result states: PASS, FAIL, NOT_APPLICABLE, INCONCLUSIVE.

Conformance dimensions include parsing, identity, schema resolution, metadata inheritance, Behavior binding, channel binding, security lifecycle, streaming, generated documentation, and generated tests.

A conformance claim MUST state protocol version, supported channels, unsupported optional features, and test results.
